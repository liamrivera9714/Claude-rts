# 烽火急令

一个即时战略网页游戏，由回合制的《烽火疆域》孵化而来：同一套兵种相克和沙盘画风，改成实时的采集、建造、练兵、攻城。3D 画面，用 Three.js（r128，从 cdnjs 加载）渲染立体的地形、建筑和兵种，带实时阴影。单文件，无需构建，联网状态下直接用浏览器打开 `index.html` 即可游玩（手机竖屏会生成竖版地图）。

## 玩法

- 蓝方是你，红方是电脑。摧毁敌方都城获胜，自己的都城被毁则落败。
- 点选或拖框选中单位，再点地面移动、点敌人进攻、点金矿采集。电脑上右键同样可以下令；双击单位选中全部同类。
- 民夫采金并交回都城或驿站，也负责建造：民居（人口 +6）、兵营、箭塔、驿站。
- 都城训练民夫，兵营训练步兵、弓兵、骑兵。步兵克骑兵，骑兵克弓兵，弓兵克步兵，克制时伤害加半。
- 金矿会采空，地图中部的矿更富，需要出去争。都城每 3 秒自带 2 金税收。
- 镜头：滚轮或双指缩放，右键拖动、双指拖动或方向键平移，点“全景”复位。
- 键盘：1–4 对应军令栏按钮，A 选中全军，F 找闲置民夫，空格或 P 暂停，Esc 取消。

三档难度决定电脑的采集效率、兵营数量和首次进攻的时间。
